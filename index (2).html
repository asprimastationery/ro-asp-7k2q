Cara update data (khusus admin)
  1. Di Accurate Online, export rincian penjualan per barang 12 bulan terakhir ke Excel. Kolom yang dipakai cukup 7: Tanggal, No. Faktur, Pelanggan, Nama Barang, Kategori, Kuantitas, Satuan. Kolom lain diabaikan.
  2. Tekan Upload export Accurate. Boleh pilih beberapa file sekaligus; faktur yang sama hanya dihitung sekali. Kalau kolom tidak cocok, tekan Atur kolom.
  3. Setiap upload mengganti seluruh data lama. Cocokkan jumlah faktur di pratinjau dengan Accurate.
  4. Isi password untuk sales, tekan Buat file data.enc.json, lalu upload file itu ke repositori GitHub (Add file → Upload files → Commit changes).
